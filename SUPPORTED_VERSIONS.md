# Supported Versions

Athena Frontend has not yet reached a `1.0` release (`package.json` currently declares
version `0.0.0`, and no tagged GitHub release exists yet). The project is under active,
single-line development.

## Policy

| What | Supported? |
|---|---|
| `master` branch (latest commit) | ✅ Yes — this is the only supported version |
| Tagged releases | Not yet published — see [`CHANGELOG.md`](CHANGELOG.md) |
| Forks / long-lived feature branches | ❌ Not supported by maintainers |

There are no LTS branches. Once tagged releases begin, this document will be updated to
reflect which versions receive fixes, following [Semantic Versioning](https://semver.org/).

Security reports should always be filed against the current `master` — see
[`SECURITY.md`](SECURITY.md).
